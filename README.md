# Sitio demostrativo — Diagnóstico GSC

Sitio estático preparado para publicar en GitHub Pages y utilizarlo como proyecto de práctica en Google Search Console.

Antes de publicar:
1. Reemplazar TU-USUARIO y TU-REPOSITORIO en `robots.txt` y `sitemap.xml`.
2. Publicar mediante GitHub Pages.
3. Verificar la propiedad en Search Console.
4. Enviar `sitemap.xml`.
5. Solicitar indexación de las URLs estratégicas.
6. No incluir `no-index.html` en el sitemap: está marcada deliberadamente como `noindex`.
